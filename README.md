A program that draws an invented passport spread for the Republic of Thalverra, a North Atlantic island of herring fishers: a data page for holder Maren Elise Dahl, with a portrait and a machine-readable zone, and a visa page with arrival and departure stamps and the harbour-master's Condition 7.

## Run it

```sh
node main.ts
```

This writes `/output/entry.png` (a 1024×1024 PNG). Pure Node 22, no dependencies: the program carries its own PNG encoder, a canvas rasteriser, and a vector-font renderer fed by `glyphs.json` (DejaVu outlines, flattened to polygons).
